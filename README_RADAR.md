# Радар Європи | Безпека — бот для Telegram

Файл `bot.py` — отдельный бот для подготовки и ручного подтверждения постов. Старый `parser.py` остаётся без изменений. Новостной мониторинг ChatGPT **пока не подключён**: сейчас бот принимает вручную отправленный текст в личном чате.

## Запуск на Windows

1. Скачай этот репозиторий (зелёная кнопка **Code → Download ZIP**) или обнови его командой `git pull` в уже существующей папке.
2. Убедись, что установлен Python: `py --version` в PowerShell.
3. В папке репозитория установи зависимости: `py -m pip install -r requirements.txt`.
4. Скопируй файл `.env.example` в `.env` (в PowerShell: `Copy-Item .env.example .env`).
5. В `.env` заполни `BOT_TOKEN` токеном **твоего существующего** бота от @BotFather. Не публикуй токен, не отправляй его сюда. Оставь `CHANNEL_ID=@UA_in_DE_news`, если адрес не менялся.
6. Останови прежний процесс бота, если такой запущен: только один процесс должен опрашивать Telegram этим токеном. Запусти: `py bot.py`.
7. В личном чате с ботом отправь `/id`, скопируй числовой ID, останови программу `Ctrl+C`.
8. Запиши ID в поле `OWNER_ID=` файла `.env` и повторно запусти `py bot.py`.
9. Отправь боту `/test` и нажми **«❌ Відхилити»** для первой безопасной проверки кнопок. Затем отправь свой текст и используй **«✅ Опублікувати»**, если готов действительно опубликовать его в канале. Кнопка **«🗂 В архів (тихо)»** публикует пост с пометкой АРХІВ, с отключённым звуком уведомления.

## Команды

- `/id` — показать Telegram ID для настройки.
- `/start`, `/help` — описание действий.
- `/test` — создать тестовый черновик без публикации.
- Любой текст, отправленный владельцем в личном чате, — новый черновик.

## Важное

- Бот принимает действия публикации только от `OWNER_ID`. До задания ID публикация закрыта.
- Создание черновика **ничего не публикует**. Отправка в канал возможна только после подтверждения кнопкой владельца.
- `drafts.sqlite3` — локальная база черновиков (файл должен быть в `.gitignore`).
- Старый `parser.py` не запускай одновременно с новым ботом, если не хочешь получать старые автоматические посты.
- Для текущей версии нужен работающий компьютер с запущенной командой `py bot.py`.
- Telegram-бот бесплатен; хостинг и платный ИИ не используются.
- Telegram Bot API не даёт боту читать всю старую историю канала и массово удалять старые посты. Удаление старых сообщений пользователь выполняет самостоятельно.
- Если отправка Telegram прошла успешно, но процесс неожиданно прервался до фиксации результата в локальной базе, повторное нажатие теоретически может создать дубль; перед повторной отправкой проверь канал.

## Безопасность

Никогда не вставляй реальный токен в GitHub и не присылай его в переписку. Если токен где-то был опубликован, немедленно отзови его через @BotFather и выпусти новый.
